# Sky Stack

One perfect landing at a time.

Stacking arcade game. Tap to drop each moving block. Keep the overlap and build as high as you can.

## Play and host

Double-click index.html to play locally after extracting the ZIP. The game is bundled into that file and does not require a local server. For GitHub Pages, enable Settings → Pages → GitHub Actions. The included workflow publishes the standalone game.

Expected URL after deployment: https://kofidon99.github.io/sky-stack/

## YouTube

Upload the contents of youtube/ as a separate Playables bundle, with index.html at its root. This is a pitch build, not a certified release. SDK testing, real Android/iOS checks, metadata and platform review are still required. No licensed team or vehicle branding is included. Chess rules use the bundled chess.js library; its BSD license is in vendor/chess-LICENSE.txt.
